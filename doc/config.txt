
This file documented the legacy `./configure` build option set, which
was removed in NTL 12.0 as part of the migration to a single Meson +
Python build path. The legacy build path no longer exists.

For the current build documentation:

  doc/build.txt                    -- primary build guide
  doc/migration-from-makefile.txt  -- migrating from ./configure && make
  doc/wizard.txt                   -- auto-tuning Wizard (replaces TUNE=auto)

The full list of Meson options is also available via:

  meson configure build
